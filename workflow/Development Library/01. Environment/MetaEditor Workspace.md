# MetaEditor Workspace

## Overview
A MetaEditor workspace groups MQL5 files and projects for efficient MT5 development.

## Workspace Setup
1. Open MetaEditor.
2. Create a new workspace or configure an existing project.
3. Add the GCFIOS MQL5 project files to the workspace.
4. Organize Expert Advisors, indicators, libraries, and scripts into logical folders.

## Recommended Layout
- `Experts/` — Trading strategies and Expert Advisors.
- `Indicators/` — Custom indicators.
- `Libraries/` — Shared utility functions and architecture modules.
- `Scripts/` — one-off tools and support scripts.

## Best Practices
- Use consistent naming conventions for files and classes.
- Keep workspace projects aligned with repository folders.
- Regularly refresh the workspace after file changes.
- Use MetaEditor compilation output to catch syntax and build errors.

## Notes
MetaEditor workspace configuration should mirror the repository structure and make it easy to compile and test MT5 code.
