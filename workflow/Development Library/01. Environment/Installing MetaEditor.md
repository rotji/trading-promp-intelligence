# Installing MetaEditor

## Overview
MetaEditor is the integrated development environment for MetaTrader 5. It is required for creating, compiling, and debugging MQL5 Expert Advisors, indicators, and scripts.

## Installation Steps
1. Download MetaTrader 5 from the official broker or MetaQuotes website.
2. Install MetaTrader 5 normally by running the downloaded installer.
3. Launch MetaTrader 5.
4. From the toolbar, open `MetaEditor` or press `F4`.
5. If MetaEditor is not installed automatically, follow the prompts to install it from within MetaTrader.

## Recommended Configuration
- Enable line numbers.
- Set tab size to 4 spaces.
- Configure auto-complete for MQL5.
- Enable syntax highlighting and error checking.
- Set workspace defaults for new files.

## Notes
MetaEditor is the authoritative environment for compiling MQL5. Use it in parallel with VS Code for documentation and non-MQL5 development tasks.
