# Installing MetaTrader 5

## Overview
MetaTrader 5 is the trading platform used for market data, order execution, account management, and testing GCFIOS trading logic.

## Installation Steps
1. Download MetaTrader 5 from a supported broker or from the official MetaTrader website.
2. Run the installer and accept the default installation path.
3. Complete the installation.
4. Launch MetaTrader 5 and log in with demo or live account credentials.
5. Open the `Navigator` panel and confirm the account, indicators, and expert advisors are visible.

## Recommended Configuration
- Set data folder and terminal path to a stable location.
- Configure the market watch and chart templates.
- Enable `AutoTrading` if testing automated strategies in demo mode.
- Configure `Tools > Options` for charts, expert advisors, and terminal settings.

## Notes
MetaTrader 5 provides the runtime environment for MT5-specific development. It must remain installed and updated for testing and deployment.
