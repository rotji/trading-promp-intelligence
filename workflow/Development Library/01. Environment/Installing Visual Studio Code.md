# Installing Visual Studio Code

## Overview
Visual Studio Code (VS Code) is the primary code editor for GCFIOS development. It provides extensions, debugging support, Git integration, and editing tools for both Python and MQL5.

## Installation Steps
1. Open the official VS Code website: https://code.visualstudio.com/
2. Download the Windows installer.
3. Run the installer.
4. Select "Add to PATH" and "Register Code as an editor for supported file types.".
5. Complete installation.

## Recommended Extensions
- `ms-python.python` — Python language support.
- `ms-vscode.cpptools` — C++ support if using MQL5 and native code.
- `eamodio.gitlens` — Git history and repository intelligence.
- `esbenp.prettier-vscode` — Formatting for supported files.
- `vscode-icons-team.vscode-icons` — File icons for improved navigation.
- `ms-vscode-remote.remote-containers` — Optional if using containerized environments.

## Setup Checklist
- Confirm VS Code runs from the Start menu.
- Verify Python extension installs successfully.
- Configure user settings for tab size, format-on-save, and file associations if needed.
- Set workspace to the `trading promp intelligence` root folder.

## Notes
Use VS Code as the central development hub for editing documentation, scripts, and integration code. For MQL5-specific editing, use MetaEditor alongside VS Code when required.
