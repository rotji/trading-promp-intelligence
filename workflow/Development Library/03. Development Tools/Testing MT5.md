# Testing MT5

## Overview
Testing MT5 code ensures trading logic behaves correctly across market conditions and timeframes.

## Strategy Tester
1. Open MetaTrader 5.
2. Open the Strategy Tester (`Ctrl+R`).
3. Select the Expert Advisor or script.
4. Choose symbol, timeframe, and testing model.
5. Run backtests and review results.

## Test Types
- Backtesting on historical data.
- Forward testing in a demo account.
- Sensitivity testing across parameters and symbols.

## Validation Steps
- Validate order entry and exit logic.
- Verify stop loss, take profit, and risk calculations.
- Confirm behavior under fast market conditions.
- Review detailed reports and charts.

## Notes
Use the Strategy Tester for repeatable validation and compare results against expected behavior before deployment.
