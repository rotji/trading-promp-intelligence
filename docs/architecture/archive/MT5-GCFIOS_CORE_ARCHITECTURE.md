# GCFIOS Core Architecture

This document defined GCFIOS Core as the foundational shared layer for an MT5 implementation, including MQL5-specific interface/implementation file conventions and the MT5 library compilation model.

The architecture has been superseded by the universal platform-first architecture in which GCFIOS Core is client-independent and MT5 is Client One through an adapter boundary.
