# MT5\n\nMT5-specific engineering notes for GCFIOS.

## Key Standard

The primary file-creation workflow is:

1. Create folders and source files in Windows Explorer.
2. Open and edit them in MetaEditor.
3. Compile and debug in MetaEditor.

For the full standard, see [FILE_CREATION_STANDARD.md](FILE_CREATION_STANDARD.md).\n
