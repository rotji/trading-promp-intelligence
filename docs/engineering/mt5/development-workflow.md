# Development Workflow\n\nRecommended development workflow for MT5.

## Standard Workflow

1. Create folders and source files in Windows Explorer.
2. Open the files in MetaEditor.
3. Implement or update the code.
4. Compile and test in MetaEditor.
5. Repeat until the component is ready.

The MetaEditor Wizard is optional and should be used only for template generation, not as the standard GCFIOS development workflow.\n
