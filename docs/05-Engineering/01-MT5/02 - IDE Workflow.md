# MT5 Development Workflow

## Objective

Define the standard GCFIOS workflow for developing MT5 components.

---

## Standard Workflow

1. Create the required folder structure in Windows Explorer.
2. Create the necessary source files in Windows Explorer.
3. Open the files in MetaEditor for editing.
4. Compile and test in MetaEditor.
5. Iterate on the implementation until it is stable.

## Notes

- Windows Explorer is the standard tool for creating folders and source files.
- MetaEditor is used for editing, compiling, and debugging.
- The MetaEditor Wizard is optional and should be treated as a template-generation helper only, not the primary GCFIOS development workflow.
